# SPACE RETRO

A lightweight score-attack arcade shooter built for YouTube Playables, with mobile and desktop support.

## Play

GitHub Pages URL after Pages is enabled:

https://shute2004.github.io/space-retro-playable/

## Features

- Mobile touch controls and desktop keyboard/mouse controls
- Score-based difficulty scaling
- Localized UI for English, Japanese, Spanish, Portuguese, French, German, Italian, Korean, Simplified Chinese, Traditional Chinese, Indonesian, and Russian
- YouTube Playables SDK integration
- Cloud save and score submission in the Playables environment
- Rewarded continue ads and periodic interstitial ads in the Playables environment
